Submit step stripped only when the refined last action is a submit call (m6). Paired n = 126 unless noted. Joint percentile CIs can sit asymmetrically around the point estimate: a resampled Honest-550 has fewer distinct tail values, so its randomized threshold shifts discretely; the attack-only CIs (column `ci_attack_*` in contrasts.csv) are the project's original interval type.
